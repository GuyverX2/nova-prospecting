Nova — varför

  1. 1Zon + löfte i rubriken — "webbprospektering" och "agenten skickar aldrig själv" sätter tryggheten direkt.
  2. 2Läge som kort — webbhämtning på/av + fail-closed visas som status, inte som en teknisk sida.
  3. 3Pipeline i fem steg — upptäckt → analyserar → kvalificerad → förslag redo → godkänd. Ett prospekt = ett tillstånd.
  4. 4Evidensbalkar — slutsatser med förtroende, inte råa vektorer.
  5. 5Förslag = utkast — "ej skickat" alltid synligt tills människan godkänner.
  6. 6Rådata på begäran — site-analysis, vektorer, provider-status i backend.
